# Contributing to qBittorrent Mankka's Edition

Thank you for your interest! This edition is maintained by one person in their free
time, so please be patient.

## Ideas and feature requests

Ideas are very welcome — that's one of the reasons this edition is public.
Open an issue with the **"Idea / feature request"** form and describe:

* what you'd like the program to do,
* why it would be useful (what problem it solves for you),
* how you imagine using it.

## Bug reports

Open an issue with the **"Bug report"** form. Please include:

* the edition's version (window title or Help → About),
* your Windows version,
* what happened, what you expected, and the steps to make it happen again.

Before reporting, check whether the same problem also happens in the official
qBittorrent. If it does, it's a qBittorrent problem rather than an edition problem.

## Pull requests

Pull requests are welcome, but please open an issue first to talk about the change.
Keep each pull request to one change, and follow the existing code style
([CODING_GUIDELINES.md](CODING_GUIDELINES.md)). By contributing you agree that your
contribution is licensed under the same licence as the project (see [COPYING](COPYING)).

## Language

Issues and pull requests in **English** please, so everyone can follow them.

## The official qBittorrent project

This edition is **not** part of the official qBittorrent project. Please don't open
issues or pull requests there about anything in this edition.
